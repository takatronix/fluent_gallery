# UI v3 指針 — 「フォルダが主語」(2026-09-03、ユーザー承認済みの仕切り直し)

v2の失敗分析: 検索ツール(絞る→保存)の骨格にフォルダ/エージェント概念を増築した結果、
「＋新規なのに今の画像が見える」「機械の入り口って何」等の概念衝突が多発。以後この指針が正本。

## 憲法(5条)

1. **フォルダが主語。** 開く=そのフォルダの中身だけが見える。上部にそのフォルダのルール(目標/エージェント/成績)。
   グリッドに「今なにを見ているか」以外の画像を混ぜない
2. **新規フォルダは空で生まれる。** ＋を押したら空のフォルダビュー+設定ヘッダ。
   空状態の文言「目標を書いて ▶ を押すと、ここに集まり始めます」。既存画像は絶対に見せない
3. **検索は別レイヤ。** 検索/フィルタチップは「今見ている物を絞る虫眼鏡」。
   全体検索は検索モード(ヘッダに「検索結果」明示、✕で元のフォルダへ戻る)。フォルダと混ぜない(ml-hub IAの教訓)
4. **ユーザー語彙だけ使う。** 「機械の入り口」「入荷」等の実装説明ラベル禁止。
   フォルダ/お気に入り/データセット/取り込み、まで
5. **ネイティブdialog禁止・保存ボタン禁止。** prompt/alert/confirm不使用、編集は自動保存、
   破壊操作はundo可能にして確認を省く
6. **絵文字アイコン禁止(2026-09-03指示)。** UIクロームはvlabor風のシンプルなストロークSVG
   (24x24 / stroke-width 1.8 / currentColor)。fluent_dojoのavatarMarkup/navアイコンと同系統

## 画面構造

```
サイドバー                     メイン
──────────────               ┌ ヘッダ(今いる場所の説明+操作) … フォルダならルールパネル
ライブラリ                    ├ ツールバー(検索/絞り込みチップ/並び替え/サイズ) … 今の場所を絞る
  🖼 すべて                   └ グリッド(今の場所の中身だけ)
  ⭐ お気に入り
  🕐 最近の取り込み
フォルダ              ＋      フォルダ種別: 🤖AI(目標で自動収集) / 🔍スマート(条件) 
  🤖 かわいい犬 66            ネスト可・⧉複製・🟢/♻バッジ
  📁 植物/…
ソース(折りたたみ既定)         取り込み元の自動グループ(読み取り専用スマートフォルダ)
出荷                          📦 データセット(スナップショット・読み取り専用)
AI稼働状況                    収集/VLM/LLM/取込 + GPU/RAM
──────────────
```

## 状態モデル(実装契約)

`loc = {type: 'lib'|'folder'|'source'|'dataset'|'search'|'new', key, criteria}` の単一状態。
- グリッドは常に `loc.criteria`(+ユーザーの絞り込みチップ)の結果
- URLハッシュ=locの完全シリアライズ(コピペ復元は維持)
- 検索欄に入力→ `loc.type='search'`(直前のlocを記憶、✕/空で復帰)

## 移行メモ

- サーバAPIは無変更(albums/datasets/crawl/edits/keep/trash/llm/activity 全部生きてる)
- ライトボックス(ズーム/編集/没入/来歴カード)・FLIP・実況drop・選択モデルはv2の実証済み部品を流用
- v2は web/index-v2-backup.html に保存
